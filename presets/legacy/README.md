# Legacy presets

Historical synthesis patches, excluded from the factory menu and distribution.
`hihat.fit.json` is the previous factory hi-hat, kept for the original migration
audio regressions. Do not regenerate those golden measurements against the new
factory patch: the preset change is intentional, not an engine parity failure.

Current factory presets live in `../factory`. Reference recordings, audition
fits and experimental renders are local development data, not distributed here.
