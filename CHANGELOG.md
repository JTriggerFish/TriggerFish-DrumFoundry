# Changelog

## 0.5.0

- Modular percussion engine with CLAP and standalone audio/MIDI applications.
- Native editor with live sound design, modal editing, reference analysis,
  presets and undo/redo.
- Reusable rim-contact interaction for metallic and membrane resonators.
- Single-click access to the routing editor.
- Compact performance controls, repeatable frozen pad strikes, and module bypass
  that retains contact settings.
- User manual and updated native-editor screenshot.
- Shared product version for native builds, plugin metadata and Python tools.
